API docs tools compared

Scalar Docs · GitBook · Docusaurus · Mintlify — researched 9 Nov 2026 from vendor docs, pricing pages, and repos.

Scalar Docs

Hosted SaaS · docs-as-code · renderer MIT
$125/mo yearly · Pro, 5 editors
  • Best native API reference: OpenAPI 3.x + AsyncAPI
  • MDX, PR previews, CLI deploy, rollback
  • llms.txt, Ask AI, and MCP on every site
  • No GitLab, GraphQL, or i18n
API-first teams that live in Git

GitBook

Hosted SaaS · WYSIWYG + 2-way Git · renderer GPLv3
$65/site/mo + $12/user · Essential
  • Block editor for non-developers
  • 2-way GitHub and GitLab sync, change requests
  • "Test it" console is powered by Scalar
  • No custom CSS/JS; fixed layout; badge stays
Mixed teams where writers don't use Git

Docusaurus

Open-source static site generator · MIT · Meta
$0 + your hosting
  • Full React/MDX control, swizzling, plugins
  • Best versioning and i18n of the three
  • API reference, search, llms.txt, MCP = plugins
  • No roles, SSO, or private docs
Zero budget, full control, many locales

Mintlify

Hosted SaaS · docs-as-code + browser editor · closed
$0 · Starter, 5 editors, custom domain
  • Widest API coverage: OpenAPI 3.2, AsyncAPI, GraphQL
  • Free tier has search, MCP, API playground
  • Custom CSS/JS and React components on all plans
  • Analytics, previews, AI: $450/mo jump
Public API docs, fast — what Circle uses

Bars share one scale ($500 = full). Scalar scales by API count (3 / 15 / 25). GitBook scales per site plus per user. Mintlify Pro has unlimited editors; OAuth/JWT reader login is Enterprise. Docusaurus has no license cost.

Which one to pick

MintlifyPublic API docs with REST, async, and GraphQL APIs. Start free. Circle's choice.
Scalar DocsYou need private docs, analytics, or AI on a budget, and your team works in Git.
GitBookWriters who don't use Git produce most of the content.
DocusaurusZero budget, deep customization, or many locales. Add docusaurus-openapi-docs or embed the MIT Scalar API Reference.
